# Xiongyule Zhou

Academic homepage for robotics, robot learning and mechatronics.

The website uses static HTML, CSS and JavaScript. Images and demonstration videos are stored in `assets/`; research manuscripts are in `papers/`. GitHub Pages publishes the repository root from the main branch.

The site is publicly accessible without sign-in.

## Application-focused presentation

The homepage presents engineering projects in one chronological list, with individual contributions, results and expandable image galleries. Three selected retrospective manuscripts are displayed. Earlier original PDFs remain as unchanged historical assets; their links are not promoted in the current page.

The ALOHA cover is a clear hardware photograph. The participant-confirmed personal video frames appear only in the detail gallery. Captions remain in the image viewer. The original portrait is retained, with a compressed WebP used for delivery.

Design references: Jiajun Wu (https://jiajunwu.com/): compact visual research entries; Phillip Isola (https://web.mit.edu/phillipi/www/): highlighted work and direct artifact links; Dorsa Sadigh (https://dorsa.fyi/): concise introduction and research focus. Existing static architecture, GitHub Pages hosting and public access are retained.

## Continue on another computer

Clone this repository, run `python -m http.server 8765` in its root, and open http://localhost:8765/ . No framework or build step is required. Review edits locally, then commit and push to `main` to update GitHub Pages.
