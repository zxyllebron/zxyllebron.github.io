# Xiongyule Zhou

Academic homepage for robotics, robot learning and mechatronics.

The website uses static HTML, CSS and JavaScript. Images and demonstration videos are stored in `assets/`; research manuscripts are in `papers/`. GitHub Pages publishes the repository root from the main branch.

The site is publicly accessible without sign-in.

## Application-focused presentation

The homepage foregrounds three photographed engineering projects, makes individual contributions explicit, and presents three selected retrospective manuscripts: R09 (demonstration data), R02 (policy inference) and R05 (feedback monitoring). The full manuscript-library interface is removed. Earlier original PDFs remain as unchanged historical assets; their links are not promoted in the current page. Supporting coursework and project galleries remain in a native disclosure.

The ALOHA lead image is the screenshot in which the user identified himself. Other participant-centred or subtitle-bearing documentary frames have been removed from its displayed gallery. An additional frame is cropped to the active video picture; no synthetic participant image is used. The original portrait is retained, with a compressed WebP used for delivery.

Design references: Jiajun Wu (https://jiajunwu.com/): compact visual research entries; Phillip Isola (https://web.mit.edu/phillipi/www/): highlighted work and direct artifact links; Dorsa Sadigh (https://dorsa.fyi/): concise introduction and research focus. Existing static architecture, GitHub Pages hosting and public access are retained.
